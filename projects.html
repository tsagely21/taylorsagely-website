EZ CUSTOMZ Website & Booking System

Web Development

A live website and booking system for EZ CUSTOMZ, a custom starlight headliner and car audio shop in Baton Rouge, Louisiana. The site lets customers build an instant quote and request an appointment online, while giving the shop a private admin panel to manage its schedule. Live at ezcustomz.co.

  • Built an instant quote builder where customers pick a vehicle, services, and options and see a live price estimate and deposit, plus a booking calendar that automatically greys out confirmed bookings and days off.
  • Developed a secure admin panel to accept, decline, or cancel requests and block days off, backed by Supabase Postgres with row-level security and admin-only database functions.
  • Delivered a responsive, accessible front end in plain HTML, CSS, and JavaScript with a swipeable photo gallery, seasonal sale pricing, and light/dark mode, deployed on GitHub Pages with a custom domain.
